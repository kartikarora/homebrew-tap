# kartikarora/homebrew-tap

Official Homebrew tap for [Kartik Arora's](https://kartikarora.me) software and tools.

## Installation

Add this tap to your Homebrew installation:

```bash
brew tap kartikarora/tap
```

## Available Formulas & Casks

### Citadel
Native macOS command center and CLI for managing AI coding skills & MCP servers.

- **Desktop Application (macOS Cask):**
  ```bash
  brew install --cask kartikarora/tap/citadel
  ```
- **CLI Utility:**
  ```bash
  brew install kartikarora/tap/citadel
  ```

### Klaat
Command-line tool for exporting Google Docs to Markdown codelabs.

- **Release Build:**
  ```bash
  brew install kartikarora/tap/klaat
  ```
- **Snapshot (Preview) Build:**
  ```bash
  brew install kartikarora/tap/klaat-snapshot
  ```
